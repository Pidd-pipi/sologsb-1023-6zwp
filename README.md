# 校异斋 · 多版本文本自动比对与人工校勘工具

面向古籍和长文本编辑的多版本校勘工作台。可导入同一作品的不同版本，自动按段落与句子对齐，再由人工修正错位、判断增删改并导出校勘记。

## 功能

- 导入或粘贴同一作品的不同版本，按空行分段，再按句末标点切句。
- 自动对齐按 24 个句段一组让出浏览器主线程，长文本处理期间持续显示进度。
- 比较规则可忽略标点或常见异体字；规则变化会重算相同、改动和疑错位状态，不改写原文。
- 人工可交换邻近底本句的配对关系、整行移动、手动标记相同/改动/新增/删减/误错位。
- 每条差异可填写校勘说明和来源，并可勾选后批量接受或一键接受全部建议。
- 支持跳转到下一处未接受差异，以及键盘操作：`Alt+↓` 下一处、`A` 接受勾选、`Ctrl/⌘+Z` 撤销、`Ctrl/⌘+Y` 或 `Ctrl/⌘+Shift+Z` 重做。
- 最多保留 50 步撤销历史，版本、规则、对齐行、校记和当前位置自动保存在 `localStorage`。
- 离线协作：每台浏览器以「整理员名称」标识，可导出完整离线草稿；网络恢复后按「底本句 × 参校本句 × 比较规则」分批合流。
  - 不同字段直接并入；同一字段（校记、来源）或接受结论冲突时并排列出双方内容，逐处选择保留本机、采用对方或并排保留，确认后才写入。
  - 底本句、参校本句原文或比较规则变化后，受影响的已接受记录自动失效并按新规则重算，须人工重新确认。
  - 跨浏览器版本编号不同但正文一致时按段落/句子序号映射；对方独有的版本随草稿带入并按本机规则重建句单元。
  - 写入前做容量探针预检：存储空间不足时拒绝覆盖、现有草稿一行不动，并自动下载合并后的完整草稿备份。
- 导出 Markdown 校勘记或完整 JSON 校勘数据。
- 桌面三栏工作区，窄屏自动堆叠；提供读屏可识别的表头、标签、状态与按钮名称。

## 技术栈

- Vue 3 + Vite + TypeScript
- Arco Design Vue 2
- 浏览器 localStorage
- 无后端服务，全部计算在浏览器本地执行

## 本地开发

```bash
npm install
npm run dev
```

打开终端显示的 Vite 地址。源码未硬编码宿主端口。

## 生产构建

```bash
npm install
npm run build
```

类型检查和生产产物会生成到 `dist/`。可用 `npm run preview` 预览。

## Docker

```bash
docker build -t sologsb-1023 .
docker run --rm -p 10023:80 sologsb-1023
```

容器内 nginx 监听 `80`，根据根端口表映射到宿主 `10023`。

## 数据说明

版本正文、对齐结果、校勘说明和撤销记录均保存在当前浏览器。清除站点数据会删除草稿，建议定期导出 JSON 或 Markdown 校勘记。

## 多机离线协作流程

1. 各整理员先在左栏「本机整理员」填写自己的名称，离线期间各自校勘，数据保存在各自浏览器。
2. 网络恢复（或需要汇合时）点击「导出离线草稿」，得到带整理员标识的完整 JSON 草稿。
3. 在汇总浏览器点击「合流草稿」选择对方文件：系统按底本、参校本与比较规则生成一个合流批次并预览。
4. 预览中逐句处理——不同字段自动并入；同字段或接受结论冲突时选择「保留本机 / 采用对方 / 并排列出来」；规则不一致时选择采用哪一套。
5. 底本句、参校本句或规则变化导致的受影响接受记录会标红提示并自动失效，确认合流后到主表重新判断。
6. 确认后才写入；容量不足会拒绝覆盖并保留双方完整草稿。合流结果可撤销。

合流以「段序:句序」定位句子，若同一版本中存在大量完全重复句，建议合流前先用人工错位调整区分。
