# 校异斋 · 多版本文本自动比对与人工校勘工具

面向古籍和长文本编辑的多版本校勘工作台。可导入同一作品的不同版本，自动按段落与句子对齐，再由人工修正错位、判断增删改并导出校勘记。

## 功能

- 导入或粘贴同一作品的不同版本，按空行分段，再按句末标点切句。
- 自动对齐按 24 个句段一组让出浏览器主线程，长文本处理期间持续显示进度。
- 比较规则可忽略标点或常见异体字；规则变化会重算相同、改动和疑错位状态，不改写原文。
- 人工可交换邻近底本句的配对关系、整行移动、手动标记相同/改动/新增/删减/误错位。
- 每条差异可填写校勘说明和来源，并可勾选后批量接受或一键接受全部建议。
- 支持跳转到下一处未接受差异，以及键盘操作：`Alt+↓` 下一处、`A` 接受勾选、`Ctrl/⌘+Z` 撤销、`Ctrl/⌘+Y` 或 `Ctrl/⌘+Shift+Z` 重做。
- 最多保留 50 步撤销历史，版本、规则、对齐行、校记和当前位置自动保存在 `localStorage`。
- 导出 Markdown 校勘记或完整 JSON 校勘数据。
- 桌面三栏工作区，窄屏自动堆叠；提供读屏可识别的表头、标签、状态与按钮名称。

## 技术栈

- Vue 3 + Vite + TypeScript
- Arco Design Vue 2
- 浏览器 localStorage
- 无后端服务，全部计算在浏览器本地执行

## 本地开发

```bash
npm install
npm run dev
```

打开终端显示的 Vite 地址。源码未硬编码宿主端口。

## 生产构建

```bash
npm install
npm run build
```

类型检查和生产产物会生成到 `dist/`。可用 `npm run preview` 预览。

## Docker

```bash
docker build -t sologsb-1023 .
docker run --rm -p 10023:80 sologsb-1023
```

容器内 nginx 监听 `80`，根据根端口表映射到宿主 `10023`。

## 数据说明

版本正文、对齐结果、校勘说明和撤销记录均保存在当前浏览器。清除站点数据会删除草稿，建议定期导出 JSON 或 Markdown 校勘记。

## 离线草稿合流

整理组在多台浏览器分别离线校勘，网络恢复时合并各版本校记和接受状态。为避免晚存草稿盖住他人判断，合流按以下规则处理：

- **按句段合流**：以底本句 + 参校本句的稳定身份（段落、句序、正文一致）对齐各草稿中的同一对句段，不依赖各浏览器自行生成的临时行 id。
- **字段级并入**：校记说明、来源、接受状态按字段分别比对。仅一方填写的字段直接并入；多方填写且结论一致的直接采用。
- **冲突并排列出**：同一字段结论冲突（含接受结论冲突）时，在合流面板中并排列出各方取值与保存时间，默认选中最近保存一方，人工确认后才写入。
- **失效重算**：每一行记录比对基指纹（底本句正文 + 参校本句正文 + 比较规则）。底本句、参校本句或比较规则变化后，受影响的接受结论自动失效并重算相似度与状态，不保留过期接受。
- **容量保护**：写入前检测 localStorage 容量，空间不足时拒绝覆盖、回滚内存状态，保留存储中的完整旧草稿。

使用方式：各浏览器离线时通过「导出校勘记 → JSON 校勘数据」保存草稿；联网后在任意一台浏览器点「合并离线草稿」，添加各方 JSON 文件，确认冲突取舍后写入。
